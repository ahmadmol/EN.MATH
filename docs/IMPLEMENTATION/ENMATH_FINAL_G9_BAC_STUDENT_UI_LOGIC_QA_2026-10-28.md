## ما تغيّر معماريًا ووظيفيًا

`SourceCurricula` واجهة عرض للكتالوجين الحاليين؛ لا تنسخ أسماءً تعليمية من الصور ولا تستبدل المستوردات. تعرض Home/Study/Book/Unit/Research/Search/Planner/Progress المراجع ذاتها. التاسع 6/19 + 4/13؛ البكالوريا 7/34 + 7/29. حالات النشر لم تتغير: `INDEX_ONLY` و`BLOCKED_EDITION_REVIEW`؛ لا دروس مصدرية معتمدة ولا اعتماد للتمارين المسودة.

الرئيسية تستخدم عناصر LazyColumn بمفاتيح ومعاملات ترتيب ثابتة محسوبة قبل الرسم. أزيل العداد المتغير داخل lazy items، والتقدم الثابت `2 / 4` و`3 / 5`، وعناوين المتابعة التجريبية، والمستويات المشتقة اعتباطًا. محطات المصدر قابلة للتصفح بمعرف البحث نفسه دون قفل وهمي أو مكافأة. `SourceWorkspaceRepository` مستقل، يحفظ آخر مرجع لكل كتاب ومحفوظات المكتبة، ويتحقق من owner/stage/edition/generation وصحة مرجع المصدر وبصمته، ويرفض البيانات التالفة دون استبدالها. لا يكتب في مخزن التعلم أو الخطة أو المحفظة.

الخطة أسبوعية افتراضيًا، مع إنجاز/وقت/مختلط وفترة هدف صريحة. اليوم والأسبوع والشهر إسقاطات زمنية على الأهداف ذاتها؛ تغيير العرض لا يبدل الخطة ولا يرحّل الأهداف. أضيف اختيار كتاب/وحدة/بحث قابل للطي مع بحث، وملخص أهداف/أُنجز/متبقٍ، وتجميع حسب المادة، وإكمال يدوي وتراجع عن آخر تغيير محفوظ، وتأكيد الحذف/النقل/الإكمال/التراجع. سجل التعديلات قابل للتوسيع تدريجيًا. حافظ JSON والـreceipts على صيغتهما؛ أضيف أمر undo دون ترحيل. التراجع هنا عن آخر تغيير فقط، مع الاحتفاظ بالنسختين في التاريخ.

التقدم يعرض الفهرسة واعتماد المحتوى وأدلة التعلم بصورة منفصلة، مع تفصيل الكتاب والوحدة وخطة الطالب. نتائج Demo الـ24 وأسئلتها محفوظة ومستقلة. نتيجة التدريب المفتوحة من التاريخ ترتبط بـ`commandId` الخاص بالمحاولة، مع استمرار الرابط القديم في عرض آخر محاولة لنفس التدريب. أضيفت مراكز مراجعة/استعداد وقوانين بحالة معلّلة عند غياب المحتوى المعتمد؛ لا جلسات امتحان أو نتائج مُختلقة.

أتيح المحلل والرسم للتاسع كأدوات مستقلة، مع نفس محرك الحل وقدراته وحدوده. سِجل التعبير المتكرر وحفظ الرسم متماثلان دون تكرار. استُبقيت تفاصيل الحل والمراجعة والتلميح والتدريب التجريبي، والملحوظات والمكتبة والإعدادات والإشعارات والجواهر. البحث يوحد الفهرس ويعالج الكلمات العربية والفراغات، ويعرض مفاهيم وأسئلة Demo تحت تسمية واضحة. أمثلة الرسم موصوفة بأنها أمثلة حتى يحفظها الطالب بنفسه.

ألوان الطالب تركوازية للتاسع وIndigo للبكالوريا في الثيمين؛ ثيم المعلم محفوظ. احتُفظ بخمسة تبويبات `study/solver/home/explore/profile` وبسياسة إخفائها في الصفحات الفرعية. تبديل الجلسة يعيد جذر التنقل ويصفّر VM الأدوات حسب generation، وليس حسب UUID فقط. العودة والتمرير يعتمدان SavedState في الجلسة نفسها؛ لا ندّعي استعادة مسودة غير محفوظة أو كامل back stack بعد تبديل الملف.

3. **السحابة:** لا Auth/OTP أو مزامنة أو معلم backend أو push scheduler أُنشئ من هذه الجولة. مسار المعلم التجريبي وبياناته محفوظان.
4. **البصر والأداء:** لم تُختبر الصور الفعلية أو قص النصوص أو IME/Back/TalkBack على جهاز. المسار virtualized ومفاتيحه ثابتة وscroll قابل للحفظ داخل SavedState للجلسة، لكن لا قياس FPS/ذاكرة/ANR ولا اعتماد أداء هاتفي. تبديل الملف يعيد جذرًا آمنًا ولا يعيد مسودات غير محفوظة.

لا تعيق هذه النوافذ حماية البيانات أو تنفيذ التعديلات المحفوظة، لكنها تمنع إعلان اكتمال التعليم المصدري والقبول البصري الإنتاجي. جميع التعديلات محلية وقابلة للمراجعة دون Commit أو Push.
