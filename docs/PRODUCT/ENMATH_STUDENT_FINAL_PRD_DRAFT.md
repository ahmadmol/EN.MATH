# EN.MATH — Student Final PRD Draft

2026-10-25 · **DRAFT / awaiting owner approval, textbooks, device acceptance and cloud decision**.

مرجع النطاق: [Validated Plan](ENMATH_STUDENT_MASTER_PLAN_VALIDATED.md). مرجع الوقائع والأدلة: [Gap Report](../AUDITS/ENMATH_PLAN_TO_CODE_GAP_REPORT.md). أسماء الكيانات أدناه عقود هدف مقترحة، وليست جداول منفذة. لا تنفيذ كود ضمن إعداد PRD.

## 1. المشكلة والقيمة

يحتاج طالب التاسع أو البكالوريا العلمي في سوريا مسار تعلم موثوقًا يستطيع استكماله باتصال محدود، يعرف منه ماذا يدرس وكيف يصحح خطأه، وينظم جميع مواده دون إلزامه بساعات أو حساب سحابي. القيمة الأساسية: شرح مفهوم → تطبيق مستقل → تفسير ومراجعة → تقدم صادق وخطة قابلة للتعديل.

المستخدمون: Guest تاسع/بكالوريا، حساب تاسع ثابت المرحلة، حساب بكالوريا ثابت المرحلة، طالب على جهاز مشترك. مشغل المحتوى والمراجع العلمي وظيفتان تشغيليتان خارج رحلة الطالب. المعلم والويب وOCR/AI الشامل والدفع النقدي ليست متطلبات هذا الإصدار.

## 2. النطاق وأولويات القبول

- Must لصحة المنتج: حفظ وعزل وهوية، إكمال مختلف عن إتقان، محتوى مراجَع، مصحح محدود صادق، مراجعة أخطاء، offline آمن، موارد بحقوق، ومخطط بكل الأنماط ضمن Student Complete.
- Must للنسخة التجريبية R1: وحدة حقيقية واحدة وحلقتها كاملة، هوية ثابتة، حفظ ومحاولة ومراجعة وخطة أسبوعية بالإنجاز، ومحتوى متاح محليًا. لا تدعي هذه النسخة اكتمال المخطط بكل أنماطه أو الكتاب.
- مسار الإنتاج: B1 ثم B2 ثم G9. كل مرحلة تستخدم البنية المشتركة من البداية، لكن نشر محتوى G9 لا يسبق اعتماد الكتابين حسب الخطة.
- Cloud اختياري بقرار D01؛ إن وُعد بحساب/استعادة أصبح Auth/Sync والأمن بوابة إلزامية لذلك الإصدار.

## 3. قواعد ثابتة وعقود الوصول

الحساب له stage واحدة غير قابلة للتغيير. Guest له localLearnerId دائم بمرحلة ثابتة؛ اختيار مرحلة أخرى ينشئ مساحة مستقلة واضحة. لا owner من الاسم/البريد. Guest يسمح له التعلم والتنزيل العام والمخطط والمحـفوظات والمكتبة المجانية؛ لا Gems ولا مزامنة. الحساب المحلي ليس حسابًا سحابيًا موثقًا. لا شرط classId/teacherId في التعلم الذاتي، ولا نقل بيانات عند logout/switch إلا بإجراء claim معتمد.

مخطط defaults: WEEKLY+ACHIEVEMENT، يشمل كل المواد يدويًا، ولا يتطلب ساعة. ملفات الفيزياء المؤهلة alwaysFree ولا يمكن لقواعد Gems حجبها. المواد بلا كورسات تظهر COMING_SOON بلا زر شراء. no manual Gems/no punitive failure.

## 5. تجربة المعلومات والحالات

التنقل الحالي مثبت حتى اعتماد D10: Home/Study/Solver/Explore/Profile مع routes فرعية. Planner/Motivation/Downloads/PDF/Privacy/Mistakes تحتاج نقاط دخول معتمدة؛ أسماؤها في مصفوفة المستقبل مقترحات وليست مسارات حالية. لا مطلب >100 route؛ modal/bottom sheet مناسب للأهداف والفلاتر والتأكيدات.

كل شاشة توثق Loading/Empty/Ready/OfflineLocal/OfflineMissing/Error+Retry/Permission/Unauthorized/Unsupported/Partial/ProcessRestore/OtherAccount حيث يلزم. لكل حالة Action واضح ومصدر بيانات؛ ممنوع شاشة نجاح لعملية لم تنتهِ. الـError يحفظ الإدخال والبيانات السابقة ما أمكن. تصميم Android adaptive يعاد استخدامه للمرحلتين دون تكرار Screens.

## 6. متطلبات غير وظيفية

| البند | معيار الإصدار/القياس |

| سلامة البيانات | صفر فقد أو خلط معروف في سيناريوهات QA الحرجة؛ لا destructive migration ولا reset balances |

| Reliability | idempotent events وversion pin وretry آمن؛ durable acknowledgment قبل إظهار نجاح دائم |
| الأداء | قياس startup/scroll/render/install/RAM/battery على جهاز ضعيف متفق عليه؛ budgets الرقمية تعتمد بعد baseline، لا أرقام قبول مفترضة |

## 7. مؤشرات النجاح والاكتمال

تُقاس محليًا أو بجمع طوعي معتمد: الوصول لمحاولة مستقلة، أداء سؤال جديد غير مساعد، مراجعة خطأ، بقاء تقدم بعد إعادة تشغيل/تحديث، نجاح تنزيل واستئناف، نسبة الأهداف الرسمية المراجعة. لا يُستعمل عدد الشاشات أو ساعات التطبيق أو Gems برهانًا على التعلم. لا analytics SDK مفترض.

Student Complete = رياضيات B1+B2+G9 وفق الطبعات، كل F01..F35 ضمن سياسة cloud المختارة، حقوق وتقييم علمي، QA أجهزة وشبكات، GO/NO-GO موقّع. يبقى هذا المستند DRAFT حتى اعتماد [D01..D16](ENMATH_OPEN_DECISIONS.md). موافقة PRD وحدها لا تفوض جميع المراحل؛ يحدد المالك أول حزمة تنفيذ.
