# تبديل الدور التجريبي

- من دور الطالب: تبويب «حسابي»، ثم بطاقة «تبديل الدور — تجريبي»، ثم «الانتقال إلى المعلم».
- من دور المعلم: تبويب «المعلم»، ثم بطاقة «تبديل الدور — تجريبي» أسفل اللوحة، ثم «الانتقال إلى الطالب».
- يمكن تمرير الصفحة للوصول إلى الزر على الشاشات القصيرة.

التبديل محلي لأغراض اختبار الواجهات فقط. يُغيّر نوع المستخدم الموجود في الجلسة، ويحتفظ باسمه وبريده وتقدّم التعلم وبيانات المنتج واللغة والمظهر. يُحفظ الدور باستخدام مستودع الجلسة المحلي الموجود، دون إضافة قاعدة بيانات أو API أو نظام Authentication جديد.

تُمسح مكدسات التنقل عند التبديل لبدء الدور الجديد من رئيسيته، دون إبقاء واجهة من الدور السابق في زر الرجوع. لا تُنقل مسودات المعاينة غير المحفوظة بين الأدوار.

الملفات: `DemoRoleSwitch.kt` (جديد)، `ReferenceProfile.kt`، `TeacherReferenceDashboard.kt`، `ENMathApp.kt`، `ProductGraphs.kt`، و`TeacherReferenceScreensTest.kt`.

أدلة البناء والاختبار في `build.txt` و`ui-tests.txt`. الاختبار الجديد يتحقق من التبديل بالاتجاهين، حفظ الاختيار بعد إعادة إنشاء النشاط، والاحتفاظ ببيانات التعلم والاسم والبريد واللغة والمظهر. اختبارات UI تُشغّل على المحاكي فقط؛ لا تُمسح بيانات الهاتف الشخصي.

نتيجة التنفيذ: Build ناجح، و5 اختبارات واجهات ناجحة على المحاكي، منها اختبار التبديل الجديد واختبارات المعلم والطالب. تم تحديث التطبيق على Redmi Note 13 المتصل (`ac190123`) وفتحه بنجاح مع الحفاظ على بياناته. أحدث APK محفوظ في `dist/EN.MATH-role-switch-debug.apk`. لم يُجرَ Commit أو Push.
