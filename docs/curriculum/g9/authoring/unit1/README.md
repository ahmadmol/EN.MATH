# الوحدة الأولى — حزمة إعداد أصلية غير منشورة

هذه ملفات تحريرية وليست بنك أسئلة يقرأه التطبيق. لم تتغير قائمة الدروس المتاحة أو نسخة الدرس التجريبي أو سجلات الطلاب.

| البحث | صفحات PDF المصدر | أمثلة محلولة | تدريب | تحقق مستقل |
|---|---|---|---|---|
| طبيعة الأعداد | 6–7 | 3 | 8 | 1 |
| القواسم المشتركة لعددين صحيحين | 8–13 | 3 | 8 | 1 |
| كسور مختزلة | 14–15 | 3 | 8 | 1 |
| الجذر التربيعي لعدد موجب | 16–21 | 4 | 8 | 1 |

كل ملف يتضمن أهدافًا ومتطلبات سابقة، تعريفات وشروحًا وصيغًا مع شروط المجال، وأمثلة ذات خطوات مبررة، وتلميحات وتصحيحًا لكل سؤال. نصوص الحزمة أصلية وليست نسخًا لتمارين الكتاب. أمثلة إنطاق المقام وتبسيط الجذور ضمن الأعداد الحقيقية فقط. تصنيف العدد يستخدم خيارات متمايزة؛ «عشري منتهٍ غير صحيح» يستثني الصحيح في الاختيارات، مع توضيح أن الصحيح عادي وعشري أيضًا.

المصدر المفحوص هو نسخة 2025–2026 ذات البصمة المثبتة في فهرس المشروع. لا يوجد دليل على مطابقة 2026–2027 أو اعتماد تربوي مستقل. جميع سجلات المراجعة الرسمية PENDING وحالة النشر DRAFT_ONLY. التحقق البرمجي من الحساب ليس اعتمادًا تعليميًا.

التحقق: `python tools/test_g9_unit1.py` و`python tools/g9_content_workflow.py validate <file>`؛ إضافة `--require-release` يجب أن ترفض الملفات الحالية. المراجع يراجع اللغة، التسلسل، الصعوبة، المشتتات والتفسيرات والدقة العلمية، ثم يوثق هويته وتاريخه ودليل مراجعته قبل أي قرار نشر منفصل.

الدروس الأربعة لا تُفعّل آليًا. يبقى درس الكسور التجريبي الموجود سابقًا وحده متاحًا. لا تمنح هذه الحزمة جواهر أو تقدمًا أو نتائج امتحان.
