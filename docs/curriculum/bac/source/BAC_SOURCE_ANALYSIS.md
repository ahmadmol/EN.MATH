# EN.MATH — تحليل مصدر رياضيات الثالث الثانوي العلمي

**تاريخ العمل:** 2026-10-27  |  **نوع النتيجة:** فهرسة بنيوية، وليست رقمنة كاملة ولا اعتمادًا رسميًا لطبعة 2026–2027.

## ما استخرجناه من الملفين

- كتاب الرياضيات، الجزء الأول — 253 صفحة PDF، غلافه يذكر **2023-2024**؛ **7 وحدات و34 درسًا / بحثًا** حسب فهرس الصفحات 8–10. أرقام الصفحات المطبوعة = صفحات PDF ناقص 1.
- كتاب الرياضيات، الجزء الثاني — 217 صفحة PDF، غلافه يذكر **2021-2022**؛ **7 وحدات و29 درسًا / بحثًا** حسب الفهرس في الصفحات 8–10. أرقام الصفحات المطبوعة = صفحات PDF.
- **المجموع: 14 وحدة، 63 درسًا/بحثًا، 470 صفحة PDF.**
- **13 قسم أنشطة و14 قسم تمرينات ومسائل** حسب رؤوس الأقسام في فهرسي الكتابين. وفي الجزء الثاني اختبارات عامة تبدأ عند ص205.
- أُعدّ جدول مرور على صفحات الملفات الـ470، لكن **لا يُمثل تحققًا يدويًا من نص ورسوم كل صفحة**.
- أُعدّت **28 مسألة تعليمية أصلية توضيحية**، ليست مقتبسة من أسئلة الكتاب وليست بديلًا عنها؛ حالتها DRAFT غير منشورة.

## اختلاف الطبعات — عائق اعتماد، لا عائق الفهرسة

الملف الأول يحمل سنة 2023–2024 والثاني 2021–2022. التسمية العامة «كتب 2026» لا تثبت بأن هاتين الطبعتين هما الكتابان المعدّلان المعتمدان في 2026–2027. أعلنت الوزارة توفر كتب معدلة لعام 2025–2026 وفق إعلان 2025-09-27 (https://sana.sy/education/2294620/). يجب إجراء مقارنة رسمية للترتيب والمحتوى والرسوم والتمارين والصفحات مع إصدار معتمد قبل النشر للطلاب.

## نطاق العمل وحدوده

تم فحص الغلافين والفهرسين وبنية المحتوى وأمثلة من دروسهما بصريًا. الملفات المنشأة هنا **ترسم وحدات المنهج ومسارات المصادر** وتحتوي جردًا لصفحات أنشطة وتمارين نهاية الوحدات، لكنها **لا تحتوي نصوص جميع النظريات والأمثلة والتمارين الأصلية ولا مفاتيح الحلول**، ولا يجوز نسبتها إلى اكتمال 100%. كل درس مقفل من حيث النشر حتى فحص صفحة صفحـة ومطابقة الطبعة وتوثيق حل التمارين.

## بنية الصف الدراسي كما تعرضها الكتب

- **انطلاقة نشطة:** إثارة سؤال أو تجربة قبل المفهوم.
- **تعريف/خاصية/مبرهنة أو قاعدة:** تبنى وفق ما يوجد فعلاً في الدرس، مع إبقاء الرموز والنطاقات والشروط كاملة.
- **مثال محلول / الحل / تدرّب:** الشرح والعمل التفاعلي، مع بيان خطوات الحل لا الجواب وحده.
- **تطوير فهمك:** أسئلة تشخيص للفهم، إن كانت موجودة في صفحة الدرس.
- **أفكار يجب تمثلها / منعكسات يجب امتلاكها / أخطاء يجب تجنبها:** أقسام مراجعة وإرشادات كما هو وارد في مقدمة الكتابين.
- **أنشطة، لنتعلم البحث، قدمًا إلى الأمام، تمارين ومسائل:** موجودة بحسب الوحدة، وتختلف تسمياتها/ترتيبها.
