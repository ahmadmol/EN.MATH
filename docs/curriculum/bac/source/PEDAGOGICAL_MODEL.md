# الهيكل التربوي للجزأين في EN.MATH

## مصدر هذا الهيكل
مقدّمتا الكتابين (الجزء الأول مطبوع 5–7، الجزء الثاني مطبوع 5–7)، ورؤوس صفحات مختارة؛ وجود نوع عنصر في الكتاب **لا يعني وجوده في كل درس**. تحقق من الموضع قبل توليد UI node.

| عنصر المصدر | تحويله في التطبيق | ملاحظات تدقيق |
|---|---|---|
| انطلاقة نشطة | `hook` قبل الشرح | لا تنسب سؤالًا من تأليفنا للكتاب |
| نشاط / أنشطة | `activity` قابل للتفاعل | قد تظهر أنشطة الوحدة في قسم مستقل |
| تعريف ومصطلحات | `definition` | حفظ الرموز الرياضية وحالات المجال |
| خواص ومبرهنات | `theorem` مع شروط التطبيق | فصل الفرضيات عن النتيجة |
| برهان | `proof_steps` | لا تختصر خطوات هامة في الجبر والهندسة |
| مثال محلول | `worked_example` | تحقق حسابي مستقل + خطوات مفهومة |
| تدرّب / تحقق الفهم | `formative_check` | يختلف عن اختبار إتقان يمنح جواهر |
| طور فهمك | `reflection` أو `concept_check` | لا تضف إن لم يرد أو أصّل كعنصر من تأليفنا |
| تمرينات ومسائل | `exercise_set` | رقم المسألة والصفحة والشكل مطلوب قبل نقلها |
| أفكار يجب تمثلها | `key_ideas` | فقرة مراجعة |
| منعكسات يجب امتلاكها | `study_habits` | إرشادات مفهومية |
| أخطاء يجب تجنبها | `common_mistakes` | تعليم التصحيح لا وصف الطالب بالخطأ |
| لنتعلم البحث | `investigation` | أسئلة مفتوحة، لا تملك دائمًا جوابًا مفردًا |
| قدما إلى الأمام | `extension` | إثراء اختياري |

## عقد المحتوى المقترح
`ContentRef` يجب أن يشير إلى `stage=BAC`, `book=1/2`, `unitId`, `lessonId`, `itemId`, `sourceId`, `sourceEdition`, `sourcePrintedPage`, `sourcePdfPage`, `reviewRevision`, `publicationStatus`, `mediaRefs`, `answerCheckerId`, `explanationId`, `editorialEvidence`.

## الرياضيات والاتجاه
استخدم Compose RTL للنص العربي، ووفّر math LTR على مستوى التعبير الرياضي فقط، مع عرض الأسس والجذور والمصفوفات والمتجهات والحدود و ∑ و ∫ والتوافيق والمعادلات بشكل سليم. لا تقلب ترتيب الإحداثيات أو حدود التكامل بسبب RTL. الرسوم ثلاثية الأبعاد تحتاج إلى مراجعة مخطط/أصول صور مستحدثة ومطابقتها بالعين.

## مراجعة تصحيح الإجابات
- السؤال ذو جواب عددي: قيمة دقيقة ككسر عند الإمكان، ورمز/مجال مسموح به، ولا تقبل NaN/Infinity.
- السؤال المكافئ جبريًا: مدقق تعبير مقيد مع شروط مجال واضحة، لا مقارنة نصية فقط.
- البرهان: rubric خطوات، لا تدعي auto-grade كاملًا.
- الرسوم: rubric معلم هندسي أو تصحيح يدوي.
- مسائل الكتب الأصلية لا تدخل النظام قبل تدقيق الصياغة والرسمة والجواب، وحفظ المرجع الحرفي لرقمها وموقعها دون نشر PDF.

## الحالة
أي محتوى يفتقر إلى تدقيق المصدر أو الطبعة أو الجواب يُعرَض بعلامة مراجعة، ولا يُكافأ كدرس مكتمل حتى اعتماد سياسة النشر.
