## التكامل والحواجز

- `CurriculumCatalog` الحالي امتد بحقل `sourceIndex` إضافي؛ بقيت مجموعات التعلم التجريبية وإصداراتها ومعرفاتها دون استبدال.
- المسار: البكالوريا → الرياضيات → الجزء الأول/الثاني → الوحدة → البحث أو قسم الأنشطة/التمارين.
- البحث يصل إلى معرف البحث الصحيح. تحفظ الخطة مرجع الطبعة والمصدر والبصمة والمراجعة، وتعرضه المكتبة كمرجع قيد المراجعة.
- أضيف النوع `SOURCE_INDEX` إلى `ContentRef` بصورة متوافقة. يُقبل في تخطيط المراجع فقط، بينما `accepts` الخاص بالتعلم يرفضه؛
  لذلك لا يُسجل درسًا مكتملًا ولا يُولد محاولة أو تعلمًا أو حدث جواهر، حتى عند استدعاء Repository مباشرة.
- لم يتغير `StudentScope` الحالي `{ownerId, stage, edition, generation}`. الكتابة إلى الخطة تستخدم نطاق الجلسة الحالي،
  وترفض المالك أو المرحلة أو الجيل القديم أو الطبعة/المصدر/البصمة المعدلة.
- لا تغيير في مفاتيح الإكمال التاريخية أو `completionRefs` أو receipt الجواهر أو UUID أو `legacyWalletKey` أو مخزن المعلم.
- لم يتغير تنسيق payload الخاص بمراجع Planner القديمة؛ لذلك تبقى إعادة الأوامر القديمة المتطابقة idempotent.
  تضاف حقول النوع والبصمة فقط إلى مراجع المصدر الجديدة.
- تقدم الـ24 درسًا التجريبي محفوظ منفصلًا عن اعتماد أبحاث المصدر الـ63؛ لا تحويل أو نسخ للإكمال بينهما.
- المحلل والرسم متاحان كأداتين مستقلتين، ولا يدعيان امتلاك مفتاح حلول الكتاب أو إكمال البحث المصدر.
- لم تُنشأ تعريفات أو براهين أو أمثلة أو رسوم أو أنشطة لكل بحث انطلاقًا من أنماط المقدمة العامة.
- لم تُنقل نصوص المسودات أو أجوبتها أو PDF أو صور الكتب إلى assets أو Kotlin. بيانات المراجعة الكاملة موجودة تحت `docs` فقط.
